# Google Cloud 数据工程服务导览

面向销售、客户和售前的业务化 Web Demo：先从业务问题出发，再逐层说明 Google Cloud 数据工程服务的适用场景、组件、使用方式、规格边界和官方资源。

## 内容范围

涵盖数据接入、消息与事件流、批流处理、流程编排、转换开发、数据治理和技术元数据等服务；不将数据库、数据仓库、对象存储或 BI 产品纳入本次导览范围。

## 本地查看

这是一个无需安装依赖的静态站点。可在仓库根目录运行：

```sh
python3 -m http.server 4181 --bind 127.0.0.1 --directory dist
```

然后访问 `http://127.0.0.1:4181/`。
